# Лента объявлений: правила проекта

Задача приходит в чате. Здесь только то, что нужно знать о репозитории.

## Что лежит

- `index.html` открывается двойным кликом: без сборки, без сервера, без npm.
- `data.js` - 60 выдуманных объявлений (`window.LISTINGS`).
- `search.js` - вся логика поиска и фильтров (`filterListings`). Работает и в браузере, и в node.
- `app.js` - отрисовка карточек и связка с полями поиска и фильтров.
- `tokens.css` - дизайн-токены (цвета, отступы, радиусы). `styles.css` - стили, только через токены.
- `test.js` - проверки поиска и фильтров: `node test.js`, должно быть `0 failed`.

## Правила

- Ничего не устанавливать, `package.json` и зависимости не заводить.
- Цвета и отступы - только из `tokens.css`, новых захардкоженных цветов в `styles.css` нет.
- Поиск и фильтры не ломать: после правки прогнать `node test.js`, должно быть `0 failed`.
- Git: в `main` напрямую не коммитить и не пушить. Работаешь в своей ветке `ник/коротко-о-задаче`,
  одна задача - одна ветка. В конце - коммит с понятным сообщением на русском, push ветки
  и pull request в `main` с `Closes #номер-задачи` в описании. Как именно - в CONTRIBUTING.md.
