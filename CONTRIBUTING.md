# Как предложить правку

Коротко: основная версия проекта — ветка `main`. Напрямую в неё никто не пишет.
Каждый делает правку в своей ветке и присылает заявку (pull request). Тесты прогоняются сами,
владелец смотрит и принимает.

## Пять шагов

1. **Возьмите задачу** во вкладке Issues и напишите в ней комментарий «беру», чтобы двое не делали одно и то же.
2. **Сделайте копию проекта у себя (fork)** — кнопка Fork вверху страницы.
3. **Заведите свою ветку** с именем `ник/коротко-о-задаче`, например `anna/sort-by-price`.
   Одна задача — одна ветка. Тогда ваши правки не сталкиваются с чужими.
4. **Сделайте правку и прогоните тесты**: `node test.js` должно показать `0 failed`.
5. **Пришлите заявку (pull request)** в `main` этого репозитория. В описании напишите `Closes #номер-задачи`.

## Правила

- Ничего не устанавливать, `package.json` и зависимости не заводить.
- Цвета и отступы — только из `tokens.css`.
- Старое поведение не ломаем: поиск и фильтры должны работать, тесты — зелёные.
- Данные только выдуманные.
