# Объявления ДВ — учебный проект

Лента объявлений с поиском и фильтрами по категории, городу и цене.
Данные выдуманные. Проект нужен для воркшопа «Разработка с ИИ в существующем проекте»:
на нём учимся вносить правки руками агента, работать в ветках и принимать чужие правки.

- Живой сайт: https://jhamidun.github.io/obyavleniya-dv/ — обновляется сам, когда правку принимают в `main`.
- Открыть у себя: скачать и дважды щёлкнуть `index.html`. Без сборки, без сервера, без npm.
- Проверить: `node test.js` — должно быть `0 failed`.
- Каждая заявка на правку (pull request) автоматически прогоняет тесты на GitHub.
  Красный крестик — правка что-то сломала, её не принимаем. Зелёная галочка — можно смотреть.

Как предложить свою правку — в [CONTRIBUTING.md](CONTRIBUTING.md). Задачи — во вкладке Issues.
